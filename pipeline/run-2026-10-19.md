## Notable findings (now in the skill's hard rules)
1. **Two subagents hallucinated success.** The orchestrator's `git diff
   master` + independent gate re-run is what caught both. This is the core
   value of the pipeline: CI tests behaviour, not spec compliance or missing
   tests; an *independent* reviewer + orchestrator verification catches gaps.
2. **localStorage unavailable in the test runtime** (Node v26 flag) — a guarded
   `setupFiles` polyfill (`tests/unit/setup.ts`) fixed it without weakening any
   test.
3. **`onMounted` → setup-time read.** Restoring history up-front (not in
   `onMounted`) removes an empty-list flash and makes the on-mount restore test
   synchronous; strictly better.
4. **CI gate false-negative.** `github_ci_gate.py` timed out on `711acc2` even
   though the real workflow was `completed/success` — the per-commit
   `check-runs` endpoint surfaced job checks for the *previous* HEAD. Cross-
   check via `GET /actions/runs?per_page=` before concluding CI is red. Added to
   the skill's hard rules + a `workflows/runs` cross-check note.
5. **Feature branches frozen after PR open; process logs (`pipeline/`) go in a
   separate `chore/` branch + PR, never appended to the feature branch** — that
   earlier `chore/pipeline-log` race got a commit orphaned by the user's manual
   merge.
